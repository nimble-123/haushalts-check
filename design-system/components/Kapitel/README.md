Der Kapitelkopf eröffnet einen Abschnitt, der dem Weg des Geldes folgt.

**Verwenden** für die drei Kapitel „Dein Brutto“, „Wohin es fließt“, „Der Bundeshaushalt im Ganzen“, in dieser Reihenfolge.

**Du lieferst** `<header class="rs-kapitel"><h2>…</h2><p>…</p></header>`: Überschrift in `heading`, ein Satz in `ink-2`, der sagt, was das Kapitel beantwortet.

**Nicht** für Unterabschnitte; Grafiken bekommen einen Titel in `subheading`.
