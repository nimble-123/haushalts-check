Der Tooltip zeigt den genauen Wert unter dem Zeiger.

**Verwenden** auf jedem Diagrammelement (Hover und Antippen); Inhalt: Name fett, darunter Betrag und Anteil.

**Du lieferst** ein einziges `<div class="rs-tip" role="presentation">` pro Seite, das per Skript positioniert und mit `opacity: 1` gezeigt wird.

**Nicht** für Informationen, die nirgends sonst stehen; alles im Tooltip steht auch in der Tabelle.
