Das Panel ist die Fläche, auf der eine Grafik steht.

**Verwenden** um jede Grafik und jede Tabelle; der Titel (`subheading`) und die Unterzeile (`small`) stehen darüber auf `paper`, nicht im Panel.

**Du lieferst** den Inhalt; breite Diagramme in `<div class="rs-scroll">`, damit nur das Diagramm seitlich scrollt.

**Nicht** verschachteln, nicht mit Rahmen oder Schatten versehen, nicht für Text-Absätze.
