Der Schätzungs-Chip kennzeichnet Werte, die nicht aus stadteigenen Zahlen stammen.

**Verwenden** neben dem Titel jeder Grafik, deren Stadt-Teil auf dem Landesdurchschnitt der Gemeinden beruht; in Diagrammen zusätzlich ≈ vor dem Namen.

**Du lieferst** `<span class="rs-schaetzung">≈ Schätzung</span>`; die Erklärung steht in der Unterzeile oder in „So ist gerechnet“.

**Nicht** als Warnung oder Fehler verwenden; es ist eine sachliche Kennzeichnung.
