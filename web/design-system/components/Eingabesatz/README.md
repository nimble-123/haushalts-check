Der Eingabesatz stellt die zwei wichtigsten Fragen als Satz: Betrag und Stadt.

**Verwenden** einmal pro Seite, im Einstieg. Darunter optional ein Aufklapper „Weitere Angaben“ mit Feldern.

**Du lieferst** einen Satz in `lead` (Klasse `rs-satz`) mit einem Betragsfeld `<input class="rs-betrag" inputmode="numeric">` und einer Auswahl `<select class="rs-auswahl">`. Beide brauchen ein `aria-label`, weil der Satz ihre sichtbare Beschriftung ist.

**Nicht** mehr als zwei Eingaben in einen Satz packen; Steuerklasse, Versicherung und Kirche gehören in Felder.
