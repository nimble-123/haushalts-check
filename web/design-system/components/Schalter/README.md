Der Schalter ist ein Kontrollkästchen für Ja/Nein-Angaben.

**Verwenden** für „kinderlos“, „Arbeitgeberanteil mitzählen“, „Netto im Diagramm zeigen“.

**Du lieferst** `<label class="rs-schalter"><input type="checkbox"> Text</label>`; der Text beschreibt den eingeschalteten Zustand.

**Nicht** für Entweder-oder mit zwei benannten Optionen; dafür das Segment.
